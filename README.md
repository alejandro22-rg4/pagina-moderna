# TechStore Modern — laboratorio HTML y CSS

Proyecto educativo de tienda tecnológica ficticia, con cinco páginas HTML, una hoja de estilos compartida e ilustraciones SVG locales. No requiere conexión a internet para verse ni dependencias externas. Los precios y datos son inventados. No hay compras reales ni envío de formularios.

## Cómo empezar

1. Descomprime el ZIP y abre la carpeta en Visual Studio Code.
2. Abre `index.html` en tu navegador.
3. Recorre el menú y observa cómo se relacionan los archivos.
4. Modifica un elemento, guarda y recarga el navegador.
5. Completa los retos y registra qué cambiaste y por qué.

## Retos para pasantes

Marca cada reto al terminarlo. No basta con cambiar texto: explica qué etiquetas, atributos o selectores utilizaste.

### Exploración y contenido
- [ ] **01. Mapa del proyecto.** Identifica los cinco HTML, el CSS y la carpeta `assets`. Explica la función de cada uno.
- [ ] **02. Marca nueva.** Sustituye TechStore por el nombre de tu empresa ficticia en las cinco páginas, incluidos los títulos del navegador.
- [ ] **03. Navegación.** Comprueba que el menú y los enlaces del pie de página funcionen. Explica `href` y las rutas relativas.
- [ ] **04. Portada.** Cambia título, descripción y botón principal en `index.html`.
- [ ] **05. Contenido propio.** Reescribe `nosotros.html` con historia, misión y tres valores originales.
- [ ] **06. Catálogo.** Cambia los seis productos por productos ficticios distintos, con nombres, descripciones y precios coherentes.
- [ ] **07. Productos nuevos.** Duplica dos tarjetas en `productos.html`. Investiga para qué sirven `article`, `class` e `img`.
- [ ] **08. Imágenes.** Cambia al menos dos ilustraciones por recursos locales propios o autorizados. Mantén rutas correctas y agrega `alt` descriptivos.
- [ ] **09. Detalle.** Haz que `detalle.html` represente uno de tus productos. Actualiza imagen, precio y tabla de características.
- [ ] **10. Página adicional.** Crea `preguntas.html` con al menos cinco preguntas frecuentes y enlázala desde todas las páginas.

### Estilos y diseño
- [ ] **11. Paleta de colores.** Cambia las variables `--bg`, `--surface`, `--accent` y `--text` en `styles.css`. Comprueba contraste.
- [ ] **12. Tipografía.** Cambia el tamaño de títulos, párrafos y navegación sin perder legibilidad.
- [ ] **13. Botones.** Personaliza `.btn` y `.pill` (colores, bordes y efecto al pasar el cursor).
- [ ] **14. Tarjetas.** Modifica `.card`, `.product-image` y `.card:hover` para crear una apariencia diferente.
- [ ] **15. Espaciados.** Investiga `padding`, `margin` y `gap` y ajusta el espaciado de dos secciones.
- [ ] **16. Diseño adaptable.** Prueba la web con las herramientas de desarrollador del navegador a 390 px y 1280 px. Corrige cualquier desbordamiento.
- [ ] **17. Formulario.** Agrega campo de teléfono opcional y una casilla de aceptación ficticia. Relaciona cada campo con su `label`.
- [ ] **18. Accesibilidad.** Revisa el orden de títulos, los textos alternativos de imágenes y la navegación con teclado.

### Entrega y reflexión
- [ ] **19. GitHub.** Sube el proyecto a un repositorio propio con al menos tres commits descriptivos.
- [ ] **20. Presentación.** Explica qué hace `index.html`, cómo se comparte `styles.css` entre páginas y muestra tres cambios de HTML y tres de CSS.

## Retos extra (si terminan antes)
- Crea una página `ofertas.html` con una tabla comparativa.
- Diseña una versión alternativa de la portada sin modificar el contenido.
- Corrige un enlace o ruta de imagen que tu compañero haya roto intencionalmente.
- Publica el sitio con GitHub Pages (repositorio público, `index.html` en raíz, Settings > Pages).

## Nota para el supervisor

La plantilla es deliberadamente más completa y moderna que un ejercicio básico, pero mantiene HTML y CSS sin frameworks. Las etiquetas de categoría del catálogo son decorativas; no realizan filtrado. El formulario es visual y no envía datos. Para los estudiantes menores de edad, evitar publicar datos personales y cualquier información empresarial.
